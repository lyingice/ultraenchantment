- **基础阶（原版·参考）**：这条附魔在原版里长什么样，只作对照，**不参与该阶级的计算**。
- **该阶实际公式**：该阶级真正生效的内容 —— 数值就是该阶级自己的公式，原版数字不参与。
  「追加」= 在原版之外再挂一条（与原版叠加）；
  「覆盖」= 把原版那一条整条换掉（结算时用效果算出的值替换当前值，所以数值写小是**变弱**）。
  ✦ 标记的是该阶级**新增**的效果（原版没有这个组件，例如给锋利加击退）。
  三种写法（覆盖 / 追加 / 增量）的边界见 docs/guide-data.md。
  条件是「这个附魔是什么」的一部分，**照原版保留**（亡灵杀手依然只打亡灵）。
- **满级合计**：只对「全部无条件加法 + 线性」的组件求和，上限取该阶级 max_level；
