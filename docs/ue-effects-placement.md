# 进阶附魔「特殊效果」附魔表

> 本表记录本次为 `ue:*` 系列特殊效果**接进哪些进阶附魔、哪一阶**。
> 数值全部写在 `LineageTable.java` 里，改数值改那里；本表只做「效果落点」的索引。
> 每一阶的实际数值以 `src/generated/.../enchantment/<阶级>/<附魔>.json` 的 `ue_effects` 为准。

## 阅读说明

- **附魔** —— 被加强的原版附魔谱系（进阶后显示为「高阶/超级/究极」）。
- **生效阶级** —— 只有升到这一阶才会点亮该效果。低阶不会「削弱版」生效，就是没有。
- **触发时机** —— 这个效果在游戏的哪个瞬间被点燃。
- **数值** —— 括号里是 `1 级的值`，`+` 后面是**每升一级**追加的量（进阶附魔自己的曲线等级）。
- 标注 ⚠️ 的，是**有代价 / 会减少收益**的效果，不是纯加强。

## 六、全局安全边界（`UEConfig` 的 `ue_effects` 组）

这些不是单个附魔的数值，而是**上限**，防止叠加过头或数据包写出失控值：

| 配置项 | 默认 | 作用 |
|---|---|---|
| `enabled` | true | 总开关，关掉后所有特殊效果失效（调试用） |
| `maxRealDamageCap` | 1.0 | 真实伤害占本次伤害的比例上限 |
| `maxDoubleProtectionPerItem` | 0.5 | 双重护体**单件**减伤上限（多件仍按乘法叠） |
| `maxEffectRecursion` | 4 | 真实伤害 / 反伤互相触发的递归深度上限 |
| `maxMultiJumps` | 8 | 多段跳的额外段数上限 |
| `autoPickupRadius` | 16 | 自动拾取回收掉落的半径 |
