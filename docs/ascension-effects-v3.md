## 实现清单（对照当前生成器）

### A. 必须改的两条模型（否则生成不出本表）

1. **数值逐条给定，不再用全局阶级倍率**。当前 `UEStages.TIERS` 是全局 (×3/×2, ×6/×3, ×10/×5)，
   由 `UEStageEffects.scaleCore` 缩放原版核心值；但本表里保护是 1.25+1.25、水下呼吸 4+4、
   多重射击散射 15（数量却是 ×3）、荆棘 ×2/×4/×8、激流 ×2/×4/×8 —— **不存在统一倍率**。
2. **阶梯长度 ≤3 且逐阶可省**。当前 `LineageTable` 静态断言「每条谱系必须有 3 阶」，
   而本表里保护 1 阶、火焰/爆炸/弹射物保护 2 阶、摔落缓冲/水下呼吸/耐久/经验修补/冲击/火矢/无限 1 阶，
   另有 5 条谱系整体移除。
   → 同时需要**逐阶 cap 覆盖**（火焰/爆炸/弹射物保护超级 = 1、摔落缓冲高阶 = 1、激流三阶 = 1）。
   → 门槛列 = 原版上限（即「满级」），取代当前的全局 5/4/3。

### B. 需要新增的生成器能力（均为原版可表达的效果组件）

| 能力 | 用到的组件 | 用在哪 |
|---|---|---|
| 无条件 `damage_protection`（去掉 requirements） | `DAMAGE_PROTECTION` | 保护高阶 |
| 指定条件的 `damage_protection` + 追加「原版保护」条目（带 `bypasses_invulnerability` 排除） | `DAMAGE_PROTECTION` | 火焰/爆炸/弹射物保护高阶 |
| `damage_immunity`（record 无字段，靠 requirements 限定伤害类型） | `DAMAGE_IMMUNITY` | 三系保护超级、摔落缓冲高阶 |
| 燃烧时间属性（`generic.burning_time`, `add_multiplied_base`） | `ATTRIBUTES` | 火焰保护高阶 |
| 荆棘：`post_attack`(attacker) → `damage_entity`(min/max) + `damage_item` + 随机概率 | `POST_ATTACK` | 荆棘三阶 |
| `ammo_use` 去条件（取消箭种限制） | `AMMO_USE` | 无限高阶 |
| `item_damage` 追加一条线性免除概率（工具） | `ITEM_DAMAGE` | 耐久高阶 |
| 属性修饰符 `add_multiplied_total`（攻击伤害 %） | `ATTRIBUTES` | 锋利超级/究极 |

> 注：耐久「护甲」条目 = 原版自带（`fraction` 分子 2+2/级、分母 10+5/级），**不再缩放**即可，无需新写。
