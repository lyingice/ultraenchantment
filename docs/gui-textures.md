# GUI 纹理重绘指南

> **目录**：`src/main/resources/assets/ultraenchantment/textures/gui/`
> **占位图生成器**：`tools/gen-gui-textures.py`（可随时重跑）
> **坐标表**：`client/GuiSprites.java`（**改图不用改代码**）

---

## 一、总览：两类资源

| 类型 | 文件 | 说明 |
|---|---|---|
| **背景** | 每屏一张 | 面板边框、槽位凹陷、列表底、分隔线**全部烘焙在里面** |
| **精灵图** | 三屏共用 `widgets.png` | 按钮 / 阶级方块 / 箭头 |

**全部 1:1 绘制，不缩放。** PNG 尺寸必须与下表完全一致，否则会拉伸或裁切。

## 四、重绘步骤

1. 打开 `textures/gui/` 下的 PNG，**保持尺寸与上表一致**
2. 画你的美术
3. 直接替换文件 —— **代码一行都不用改**
4. 若想改某个精灵的**位置**，改 `GuiSprites.java` 里对应的 `widget(u, v, w, h)`

**要改尺寸**？背景可以直接改（代码用 `PANEL_W/PANEL_H` 常量 + `imageWidth/imageHeight`），
但精灵必须同步改 `GuiSprites` 的 `w/h`。

## 五、文字颜色（不在贴图里）

文字是动态的，颜色仍在 `GuiRender`：

| 常量 | 用途 |
|---|---|
| `TEXT` `0x404040` | 正文 |
| `TEXT_DIM` `0x707070` | 次要信息（表头、数值） |
| `TEXT_OFF` `0xA0A0A0` | 禁用 / 未解锁 |
| `TEXT_BAD` `0xA00000` | 付不起 / 余额为零 |
| `TEXT_OK` `0x106010` | 成功状态 |
