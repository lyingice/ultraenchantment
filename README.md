# Ultra Enchantment · 附魔进阶

给 Minecraft 原版附魔加一条**成长线**。

原版附魔在满级之后就走到头了。这个模组让每条附魔都能继续往上走：
**原生 → 高阶 → 超级 → 究极**，而且每一阶不只是数字变大，还会**多出新本事**。

---

## 一、它到底做了什么

- **每条附魔都有自己的成长线。** 锋利有锋利的线，耐久有耐久的线，互不干扰；
  同一把剑上的几条附魔可以各自推进到不同阶段。
- **进阶改变的是附魔的「形态」，不只是数值。** 锋利走到高阶开始附带击退，到究极再附带穿甲；
  耐久、保护、荆棘、引雷这些则各自换一套更狠的算法。
- **进阶之后附魔会被「锁住」。** 砂轮洗不掉、合成修复抹不掉、铁砧合并也不会丢——
  想拿掉它，只能用**对应阶级的祛咒石**。
- **每条线可以长、可以短。** 默认三阶走到底，也可以在数据里让某条附魔只做到超级就停。

举一条看得见的曲线（锋利，每级伤害加成）：

| | 1 级 | 满级（5 级） |
|---|---|---|
| 原生 | +1 | +3 |
| 高阶 | **+3** | **+7** |
| 超级 | **+6** | **+12** |
| 究极 | **+10** | **+20** |

| 阶级 | 是什么 |
|---|---|
| 原生 | 原版附魔本身，还没进阶 |
| 高阶 | 第一次进阶 |
| 超级 | 第二次进阶 |
| 究极 | 第三次进阶（目前是终点） |

---

## 二、游戏里只有两个物品，做四件事

物品栏里你会看到「**进阶附魔书**」和「**祛咒石**」。它们的用途写在提示框上。

### 进阶附魔书

同一个物品，四种模样，靠提示框区分：

| 提示框上写着 | 作用 |
|---|---|
| 附魔进阶 | 把装备上已有的附魔推进一阶。分三档：基础→高阶 / 高阶→超级 / 超级→究极 |
| 定向进阶 | 同样的推进，但只认某一条附魔（书面上写着是哪条），用来精准控制 |
| 高阶附魔 · 高阶锋利 IV | **载体书**：直接携带进阶附魔，可以贴到装备上，也能和别的书合并 |
| 高阶升级 III | **升级书**：把已经是高阶的附魔，提到指定的等级 |

### 祛咒石

分高阶 / 超级 / 究极三档，只干一件事：**解除同档附魔的保护**。
可以反复使用、会消耗耐久；如果物品上没有对应档的附魔，它不会白扣耐久。

---

## 三、一条完整的玩法路线

1. **先把附魔养满**（原版手段都行：附魔台、村民交易、战利品、钓鱼）。
2. **用「基础→高阶」进阶附魔书把它推进高阶。** 进阶等级从 **1** 重新开始——
   这是新的曲线，不是原来的等级。
3. **用升级附魔书把等级往上提。** 提到多少，这一阶的强度就到多少。
4. **想再往上走**，重复第 2、3 步：高阶 → 超级 → 究极。
5. **想重铸或换方向**，用对应档的祛咒石解除保护，就能重新洗掉、重新来。

> 你会看到「**高阶锋利 3**」这样的名字——那个数字是**模组自己的进阶等级**。
> 装备上原本的锋利 5 不会被改动，它只决定**你够不够门槛进这一阶**。

## 四、铁砧上能做的事

| 放进铁砧 | 结果 |
|---|---|
| 装备 + 进阶 / 升级 / 载体书 | 进阶、提级，或把书上的附魔刻上去 |
| 载体书 + 进阶书 / 升级书 | 把**书本身**推进一阶，或提高书里附魔的等级 |
| 载体书 + 载体书 | 合成一本：**同一附魔同级就升 1 级**，不同附魔并进同一本 |
| 原版附魔书 + 进阶书 | **转印**成一本载体书（这是生存里获得载体书的正路） |
| 同名装备 + 同名装备 | 同一条线上阶级相同的附魔，**等级 +1**，耐久也一起修 |
| 装备 + 修复材料 | 正常修耐久，进阶附魔原样保留 |

载体书贴装备时，书上有条目用不上（阶级不对、这件装备不支持那个附魔），
**它们不会被浪费**——会回到一本「剩下一半」的书里，可以继续用在别处。

## 五、给别人留的发挥空间

「成长曲线长什么样」整个交给数据包，代码里**没有写死任何一条附魔的数值或长度**。
可以调的东西包括：

- 每条附魔的**等级上限**（逐条独立：耐久 3、保护 4、锋利 5 各是各的）
- 每一阶的**进阶门槛**（要几级才允许升上去）
- 每一阶的**铁砧花费**
- **进阶链的形状**：让某条线只到高阶就停、让高阶直接接究极、或只给一部分附魔开进阶
- **每一阶的具体效果与数值**（这一阶多打多少血、给多少击退、要不要加一个新效果）
- **附魔的名字**（「高阶锋利」可以改叫「裂空」）

于是能做出的东西包括：只给三条附魔开进阶的轻量包、把究极锋利调到 30 级的强力包、
「只有两阶但每阶质变很大」的短链、以及给整个整合包换一套命名体系。

- 手把手的数据包教程：[docs/guide-data.md](docs/guide-data.md)
- **每条附魔、每一阶的绝对数值总表**：[docs/enchantment-effects.md](docs/enchantment-effects.md)

## 六、覆盖范围

**支持 30 条常用原版附魔：**

防护 · 火焰保护 · 爆炸保护 · 弹射物保护 · 摔落缓冲 · 荆棘 · 水下呼吸 · 深海探索者 ·
迅捷潜行 · 锋利 · 亡灵杀手 · 击退 · 火焰附加 · 抢夺 · 横扫之刃 · 力量 · 冲击 · 火矢 ·
无限 · 多重射击 · 快速装填 · 穿透 · 忠诚 · 激流 · 引雷 · 效率 · 耐久 · 经验修补 ·
饵钓 · 海之眷顾

**刻意不做**：财富、精准采集（它们的效果走另一条查询路径，做进阶不安全），
以及两个诅咒附魔（进阶没有意义）。

**没有等级成长的五条**：引雷、火矢、无限、经验修补、多重射击——
它们的原版上限就是 1 级，所以升级书与合并对它们不生效，强度完全由阶级本身给。

## 七、有意为之的几件事

- 进阶过的物品在铁砧上**永远不会「过于昂贵」**；纯进阶、纯提级也不会让修理费越滚越高。
- 用进阶书与载体书时，铁砧的名字框不参与（同名装备合并时会参与，那是照原版做的）。
- 创造模式可以直接给白装备上阶级，包括直接上究极——方便调试与搭展台。
- 进阶之后只能用祛咒石解除保护，这是刻意的取舍，不是漏做。

## 八、当前状态

- 支持 **Minecraft 1.21.1 / NeoForge 21.1+**，客户端与服务端都需要安装。
- ⚠️ **配方与战利品尚未接入**：进阶附魔书与祛咒石目前只能从创造模式物品栏取得，
  生存获取途径仍在设计中。想先体验玩法，用创造模式即可。
- ✅ **JEI 兼容**：装上 JEI 后，三种科目、各阶级的进阶书（含定向书）与祛咒石
  都会**各占一格**单独列出，不会被合并成一本。
