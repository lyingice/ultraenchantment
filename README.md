# Ultra Enchantment · 附魔进阶

给 Minecraft 原版附魔加一条**成长线**。

原版附魔练到满级就走到头了。这个模组让每条附魔都能继续往上走：
**基础 → 高阶 → 超级 → 究极**。每一阶不只是数字变大，还会**多出新本事**。

---

## 一、它到底做了什么

- **每条附魔各有各的成长线。** 锋利有锋利的线，耐久有耐久的线，互不干扰；
  同一把剑上的几条附魔可以分别推进到不同阶段。
- **进阶改变的是「这一阶给什么」，不只是数值。** 例如锋利到超级开始**按总攻击伤害加成**，
  究极再额外**削弱目标护甲**；火焰保护到超级干脆**完全免疫火焰**（连着火都不会）。
- **进阶之后附魔会被「锁住」。** 砂轮洗不掉、合成修复抹不掉、铁砧合并也不会丢。
  想拿掉它，只能用**对应阶级的祛咒石**。
- **每条线可长可短。** 有的附魔只有一阶（摔落缓冲、水下呼吸、耐久、经验修补、冲击、火矢、无限），
  有的做到超级为止（火焰保护、爆炸保护、弹射物保护），其余才是三阶走到底。

举一条看得见的曲线（锋利，每级增加的伤害）：

| | 1 级 | 满级（5 级） |
|---|---|---|
| 基础 | +1 | +3 |
| 高阶 | **+3** | **+7** |
| 超级 | **+6** | **+12**（另加 **+30% 总攻击伤害**） |
| 究极 | **+10** | **+20**（另加 **+50% 总攻击伤害**、-0.25 目标护甲有效性） |

| 阶级 | 是什么 |
|---|---|
| 基础 | 原版附魔本身，还没进阶 |
| 高阶 | 第一次进阶 |
| 超级 | 第二次进阶 |
| 究极 | 第三次进阶（目前是终点） |

## 二、游戏里只有两个物品，做四件事

物品栏里你会看到「**进阶附魔书**」和「**祛咒石**」。它们的用途会写在提示框上。

### 进阶附魔书

同一个物品，四种模样，靠提示框区分：

| 提示框上写着 | 作用 |
|---|---|
| 附魔进阶 | 把装备上已有的附魔推进一阶。分三档：基础→高阶 / 高阶→超级 / 超级→究极 |
| 定向进阶 | 同样的推进，但只认某一条附魔（书面上写着是哪条），用来精准控制 |
| 高阶附魔 · 高阶锋利 IV | **载体书**：直接携带进阶附魔，可以贴到装备上，也能和别的书合并 |
| 高阶升级 III | **升级书**：把已经是高阶的附魔，提到指定的等级 |

### 祛咒石

分高阶 / 超级 / 究极三档，只干一件事：**解除同档附魔的保护**。
可以反复使用、会消耗耐久；如果物品上没有对应档的附魔，它不会白扣耐久。

## 三、一条完整的玩法路线

1. **先把附魔养满**（原版手段都行：附魔台、村民交易、战利品、钓鱼）。
2. **用「基础→高阶」进阶附魔书把它推进高阶。** 进阶等级从 **1** 重新开始——
   这是新的曲线，不是原来的等级。
3. **用升级附魔书把等级往上提。** 提到多少，这一阶的强度就到多少。
4. **想再往上走**，重复第 2、3 步：高阶 → 超级 → 究极。
5. **想重铸或换方向**，用对应档的祛咒石解除保护，就能重新洗掉、重新来。

> 你会看到「**高阶锋利 3**」这样的名字——那个数字是**进阶等级**。
> 装备上原本的锋利 5 不会被改动，它只决定**你够不够门槛进这一阶**。
>
> **进阶门槛 = 该附魔的原版满级**：锋利要满级 5、击退要满级 2、经验修补满级就是 1。

## 四、铁砧上能做的事

| 放进铁砧 | 结果 |
|---|---|
| 装备 + 进阶 / 升级 / 载体书 | 进阶、提级，或把书上的附魔刻上去 |
| 载体书 + 进阶书 / 升级书 | 把**书本身**推进一阶，或提高书里附魔的等级 |
| 载体书 + 载体书 | 合成一本：**同一附魔同级就升 1 级**，不同附魔并进同一本 |
| 原版附魔书 + 进阶书 | **转印**成一本载体书（这是生存里获得载体书的正路） |
| 同名装备 + 同名装备 | 同一条线上阶级相同的附魔，**等级 +1**，耐久也一起修 |
| 装备 + 修复材料 | 正常修耐久，进阶附魔原样保留 |

载体书贴装备时，书上有条目用不上（阶级不对、这件装备不支持那个附魔），
**它们不会被浪费**——会回到一本「剩下一半」的书里，可以继续用在别处。

标「满级」的一列，指的是**这一阶练到顶之后你能拿到什么**（阶级上限各不相同）。

|---|---|---|
| **锋利** | 高阶 / 超级 / 究极 | +7 / +12 并加 30% 总攻击伤害 / +20 并加 50% 总攻击伤害、-0.25 目标护甲 |

| **激流** | 高阶 / 超级 / 究极 | 旋冲强度 6 / 12 / 24（上限固定 1 级，强度逐阶翻倍） |
| **饵钓** | 高阶 / 超级 / 究极 | 咬钩加快 35 / 60 并加钓鱼幸运 / 100 并加钓鱼幸运 |

**没有进阶的五条**（本版未收录）：深海探索者、迅捷潜行、忠诚、引雷、快速装填。

## 六、有意为之的几件事

- 进阶过的物品在铁砧上**永远不会「过于昂贵」**；纯进阶、纯提级也不会让修理费越滚越高。
- 用进阶书与载体书时，铁砧的名字框不参与（同名装备合并时会参与，那是照原版做的）。
- 创造模式可以直接给白装备上阶级，包括直接上究极——方便搭展台、做对比。
- 进阶之后只能用祛咒石解除保护，这是刻意的取舍，不是漏做。

## 七、当前状态

- 支持 **Minecraft 1.21.1 / NeoForge 21.1+**，**客户端与服务端都要安装**。
- **祛咒石有配方**：8 个**附魔之瓶**围着任意**石头标签**（`#c:stones`）合成高阶祛咒石；
  超级版 = 8 个**哭泣的黑曜石**围着**高阶**祛咒石；究极版 = 8 个**金块**围着**超级**祛咒石。
  升级只认上一级（拿高阶石点不出究极，有探针钉着）。
- ⚠️ **书的生存获取途径仍未铺满**：进阶附魔书可由**村民交易**（附魔进阶师职业）与**战利品表**获得；
  其余书目前主要靠创造模式物品栏，完整缺口记录在 [`AGENT.md` §7](AGENT.md) 第 3 条。
- ✅ **JEI**：装上 JEI 后，各阶级的进阶书（含定向书）与祛咒石都会**各占一格**单独列出，
  不会被合并成一本；铁砧上的三类操作（**附魔进阶 / 附魔合并 / 附魔升级**）都有配方页可查，
  拿着书按 R 即可翻到。等级不用一条条铺开——同一格里会轮播，
  鼠标停上去能看到进阶要求（是要求满级，还是要求到某一等级）。
- ✅ **与「传说提示框 / Prism / 冰山」软联动**（装了才生效，不装完全不受影响）：
  装了 Prism，**究极阶**附魔行会显示成**渐变彩虹**（颜色随时间流动）；
  装了传说提示框，物品提示框里的攻击伤害数字会正确计入**阶级加伤**
  （否则它会按原版那套算法算，看不到阶级带来的提升）。
- ✅ **与「试验假人」兼容**：装了假人模组时，本模组会自动适配它的生物类型判定；
  不装则完全不参与，不会对游戏产生任何额外影响。
- ✅ **不会改动原版附魔本身**：进阶只是在你的这件装备上生效，原版附魔、原版配方、
  原版数值都照旧。

## 八、常见问题

**Q：进阶等级为什么从 1 开始？**
A：每一阶都是一条**新的曲线**，用 1 级起步最容易看懂强度。物品上原本的附魔等级不会变，
它只决定你能不能进阶到这一阶。

**Q：进阶之后怎么撤销？**
A：用**同档的祛咒石**。它不会消耗掉物品，只会解除保护；之后砂轮、重铸等原版手段就能生效了。

**Q：会和我装的其他附魔模组/整合包冲突吗？**
A：本模组只接管自己支持的那 26 条附魔；其它附魔、其它模组的行为都不受影响。
与「传说提示框 / Prism / 试验假人」已有针对性适配。

**Q：进阶后装备会变得过强吗？**
A：每阶的强度是按「原版同级再抬一截」设计的，且越高阶的成本越高（铁砧花费逐阶上升）。
具体数字见上面第五节。

**Q：多人游戏能用吗？**
A：可以，但**服务端必须也装**这个模组，否则进阶附魔无法正常结算。

**Q：能不能只让一部分附魔进阶？**
A：本版固定支持上面列出的 26 条，其余附魔保持原版不变。

## 九、给数据包作者

本模组的成长曲线**不是写死的**——把它当数据包来调整即可，不需要改动模组本体。

可以调整的内容：

- 每条附魔的**等级上限**（逐条独立：耐久 3、保护 4、锋利 5 各是各的）
- 每一阶的**进阶门槛**（要几级才允许升上去）
- 每一阶的**铁砧花费**
- **进阶链的形状**：让某条线只到高阶就停，或者干脆不给某条附魔开进阶
- **每一阶的具体效果与数值**（这一阶多打多少血、给多少击退、要不要挂一个新效果）
- **附魔的显示名字**（「高阶锋利」可以改叫「裂空」）

于是能做出的东西：只给三条附魔开进阶的轻量包、把究极锋利调得更猛的数值包、
「只有两阶但每阶质变很大」的短链，或者给整个整合包换一套命名体系。

> 具体写法与**逐条数值总表**放在仓库的 `docs/` 文档目录里，那部分是给作者的；
> 普通玩家读到这里就可以直接去玩了。
